# Agent Note: 音乐与音频文件定时关闭

Status: implemented

## Problem

视频已经支持定时暂停，宿主音乐播放器只有播放一次和循环模式，缺少按时长停止的能力。聊天语音与音乐共用音频播放器，按播放器类型判断会误把语音纳入定时。

## Decision

在音乐播放器右下角「⋮」菜单第一项提供音频定时入口，启用后显示剩余时间。复用定时面板和独立的计时状态机实例。音乐判断必须存在文档音频属性，voice=true、视频和圆形视频全部排除。按实际播放时间计时，暂停及缓冲冻结，允许同账号切歌。转入语音、视频、其他播放账号或关闭会话时取消。

Niagram 的更多菜单每次点击重新创建 ItemOptions，通过保存子菜单构造方法的参数、返回类型及 scrimView 字段取得原菜单，在宿主追加其他项之前插入定时项。原宿主固定子菜单使用 optionsButton，原有菜单监听器继续处理各自项目。循环菜单的高度限制会把追加项藏到滚动区，因此入口使用更多菜单第一项。小时为 0 时分钟范围为 1–59；其他小时为 0–59，整小时切回零小时自动选一分钟。音视频共用面板遵守相同的最小时长。

从实际音频播放器的 delegate 取得 onStateChanged(boolean,int) 方法，累计播放状态变更之间的时间。按分钟到期调用宿主暂停，拦住到期后重复及重入的结束回调；正常曲目结束透传宿主。曲目身份包含账号、对话及消息 ID，回调额外校验播放器与 delegate 实例。

playMessage 内部释放旧播放器时，delegate 可能同步看到空消息。该过渡只由外层成功播放后结算，避免系统切歌清空定时；真正关闭会话仍取消。回归夹具执行同样的释放回调顺序，移除 playDepth 保护后两项换曲测试失败，恢复后 227 项通过。

最初方案在音频面板独立提供「播完当前曲目」，旨在保留原循环模式。宿主已有播放一次的入口，该模式的收窄理由及替代关系见[音频定时只保留时长](../simplification/2026-11-25-audio-duration-only.md)。视频面板保留原有选项。

历史笔记检索：[听视频与会话共享队列](2026-11-21-listen-video.md)与界面及计时复用部分重叠，保留其视频语义；[Niagram 混淆类的结构解析](../bug-fix/2026-11-25-niagram-r8-class-discovery.md)提供类型解析约束，音频不新增短名；[系统媒体切换](../bug-fix/2026-11-25-system-media-video-skip.md)负责视频系统队列，本次音乐切歌继续透传。

## Alternatives considered

直接开启宿主播放一次可以复用循环菜单的原有行为，但会修改用户播放模式，也缺少按时长停止。

单独轮询媒体位置改动较少，但难以在下一首开始之前可靠识别结束，倍速和拖动进度也会混入计时。使用播放状态事件与单调时钟累计播放区间。

循环菜单集中播放方式，复用方便；矮播放器将新增项滚动隐藏，更多菜单第一项更容易发现。零时长可以禁用应用并提示，但滚轮动态限制可以直接避免无效选择。

## Testing

JVM 227 项回归通过，包含音频时钟、暂停和缓冲、下载等待、同账号换歌、跨账号及媒体隔离、结束回调重入、旧播放器回调、会话销毁、类型属性校验、原生 Hook 调用链以及小时分钟范围联动。反转账号比较条件后，回归出现 22 个失败，恢复源码后全量通过。Debug、Release 与 lintDebug 构建通过。

Niagram 13.2.2 正式 APK（127b70d，1322）真机确认更多菜单第一项、点击打开面板、修改时长、倒计时显示、暂停冻结与恢复，以及 0 小时排除 0 分钟、非零小时允许 0 分钟和整小时切回的联动。设备和桌面日志及截图保存在工作区 Temp/niagram-audio-timer/。

锁屏后一分钟到期只请求一次暂停，两套宿主媒体会话同时显示 PAUSED，进度保留在 123 秒。熄屏电源状态为 Dozing，倒计时仍继续。

最终测试包在 LSPosed 7912 上确认系统媒体「下一首」成功切换曲目，更多菜单继续显示剩余 14:46，未清空定时。测试后通过面板取消定时。设备安装包与交付 Debug APK 的 SHA-256 一致。Lint 为 0 错误、18 条警告。

## Consequences

音频复用宿主播放会话，不增加权限、依赖或持久化状态；独立计时实例增加一套生命周期管理。未来宿主修改 delegate 或更多菜单的构造结构时须复核，关键能力缺失时记录诊断并停用入口。

其他宿主音频能力尚未真机覆盖。流式网络缓冲、实体耳机、一次性语音、跨账号、所有循环／歌单恢复组合及听视频系统切换本轮仍需补充完整设备验收；桌面回归覆盖其中的策略与 Hook 时序。
